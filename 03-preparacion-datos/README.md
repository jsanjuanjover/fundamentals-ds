# 03 · Preparación de datos

Notebooks de referencia para dejar los datos en bruto listos para modelar. Los notebooks de otras secciones repiten solo el preprocesamiento que necesitan y enlazan aquí para los detalles.

## Notebooks

| # | Notebook | Temas |
|---|---|---|
| 01 | [Análisis exploratorio](01-analisis-exploratorio.ipynb) | Estadística descriptiva, distribuciones por clase, relaciones entre variables, correlación |
| 02 | [Limpieza de datos](02-limpieza-datos.ipynb) | Carga y enriquecimiento, tipos, duplicados, valores perdidos e imputación, valores atípicos |
| 03 | [Transformación de datos](03-transformacion-datos.ipynb) | Escalado (min-max vs z-score), codificación, discretización, ingeniería de atributos |
| 04 | [Muestreo y desbalanceo](04-muestreo-y-desbalanceo.ipynb) | Muestreo, particiones estratificadas, sobre/submuestreo (SMOTE, ADASYN, Tomek), métricas |
